# HALE Design Tokens

No final token values exist yet. Do not invent production colors, typography, spacing, radii, motion, or sound values before the corresponding brand and product decisions are approved.

## Planned token groups

- color: semantic roles, surfaces, text, feedback, data visualization
- typography: families, sizes, weights, line heights, letter spacing
- spacing: layout and component spacing scale
- size: control and icon sizing
- radius: component shape system
- elevation: shadows and layering
- motion: duration, easing, breathing phases, reduced-motion behavior
- opacity: interaction and disabled states
- audio: loudness and transition guidance where technically appropriate

## Requirements

- use semantic names rather than visual names in product code
- support light and dark contexts only when validated
- meet accessibility contrast requirements
- provide reduced-motion alternatives
- version breaking token changes
- document every approved value in the Notion Brand Bible
