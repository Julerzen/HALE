# HALE Brand Assets

This directory will hold approved, licensed, production-ready brand assets.

## Planned structure

- logos/
- icons/
- illustrations/
- fonts/
- motion/
- audio/
- licenses/

## Rules

- Do not add inspiration-board images as production assets.
- Record creator, source, license, usage scope, and modification rights.
- Store master and export formats separately.
- Provide accessible alternatives where relevant.
- Use consistent naming and versioning.
- Do not add third-party poems, quotations, music, photos, or fonts based on attribution alone.
- No logo, font, or color asset is approved yet.
